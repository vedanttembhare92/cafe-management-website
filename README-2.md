# CoffeeHub -- Café Website

A responsive café website developed using HTML, CSS, and JavaScript.

## Features

-   Home Page
-   Menu Page
-   About Page
-   Contact Page
-   Menu Search
-   Category Filtering
-   Responsive Design
-   Easy Navigation

## Technologies Used

-   HTML5
-   CSS3
-   JavaScript

## Project Structure

``` text
COFFEEHUB WEBSITE/
├── index.html

├── about.html
├── about.css
├── about.js

├── contact.css
├── contact.js
└── images/
```

## How to Run

1.  Download or clone the repository.
2.  Open the project folder in VS Code.
3.  Open `index.html` in your browser.
4.  Explore the website.

## Limitations

-   No database integration.
-   No login system.
-   No online ordering or payment.
-   No backend server.
